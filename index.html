🔌 연결 도우미 (한 번만 설치)

이 도구는 보통 웹페이지라서, 브라우저 보안 규칙 때문에 워드로·나무위키 같은 다른 사이트를 직접 읽을 수 없어요. 바이올렛몽키(Violentmonkey)에 연결 도우미를 한 번 설치하면, 단어장 탭의 버튼 하나로 워드로·나무위키에서 바로 가져와요.

설치 방법
  1. 브라우저에 Violentmonkey 확장을 설치해요. (PC 크롬·엣지·파이어폭스 / 폰은 파이어폭스 앱에서 부가 기능 → Violentmonkey. 폰 크롬은 확장 설치가 안 돼요)
  2. 📋 도우미 코드 복사 → Violentmonkey 아이콘 → ＋ (새 스크립트) → 안에 있는 내용 전부 지우고 붙여넣기 → 저장.
  3. 이 단어장 페이지를 새로고침하면 위에 "켜짐 ✅"이 떠요.

⚠️ 도우미는 이 단어장 페이지(깃허브 github.io 주소나 PC에 저장한 파일)에서만 작동해요. 폰에서 다운로드 폴더의 파일(content://)로 열면 작동하지 않으니, 깃허브에 올린 주소로 열어 주세요. 도우미는 워드로·나무위키·우리말샘·위키백과·위키데이터 외의 사이트는 절대 읽지 않아요.

📚 국어사전 파일로 뜻 채우기 (가장 빠르고 정확)

국립국어원 사전 파일을 불러와서, 뜻 없는 단어에 뜻을 한꺼번에 채워요. 워드로(wordrow) 같은 사이트의 단어도 원래 우리말샘에서 온 거예요. 여러 번 나눠서 불러와도 계속 합쳐져요.

⭐ 추천: 한국어기초사전 (제한 없이 전체 한 번에 · 뜻풀이가 쉬워서 아이들용으로 좋음)
  1. 한국어기초사전 전체 내려받기 페이지를 열어요.
  2. Json 전체 내려받기(또는 XML)를 눌러 zip을 받아요. (엑셀은 안 돼요)
  3. 아래 버튼으로 그 zip을 그대로 선택하세요.

약 5만 개 기본 단어라 양은 적지만, 끝말잇기에 자주 나오는 쉬운 단어의 뜻을 아이들이 이해하기 쉬운 말로 채워줘요.

🌐 워드로(wordrow.kr)에서 모으기 (제한 없이 · 우리말샘 단어와 뜻 · 시간이 좀 걸림)

워드로는 첫 글자만 넣으면 그 글자로 시작하는 단어와 뜻이 쪽별로 다 나와요. 워드로 페이지 안에서 도는 수집기 북마크로 모아요. (전체 약 1만 쪽 · 쪽당 1.5초 → 몇 시간, 중간에 멈췄다 이어하기 가능)

  1. 📤 수집할 글자 목록 내보내기로 파일을 받아요. (단어장에 있는 모든 첫 글자)
  2. 📋 복사 → 크롬 ☆ 북마크 추가 → 수정 → 이름 wr수집, 주소 칸에 붙여넣기 → 저장 (처음 한 번만)
  3. 크롬으로 wordrow.kr을 열고, 주소창에 wr수집 입력 → ☆ 북마크를 눌러요 → 수집기 창이 떠요.
  4. 1번 파일을 불러오고 ▶ 시작. 멈췄다가 다시 ▶ 누르면 이어서 해요.
  5. ⬇ 모은 단어 전체 txt(너무 크면 초성별로) → 여기서 📚 사전 파일 선택으로 불러오면 끝이에요.
📥 우리말샘 (100만 단어 · 하루 받을 수 있는 양에 제한이 있으면 나눠서)
  1. 우리말샘(opendict.korean.go.kr)에 회원가입 후 로그인해요. (무료)
  2. 사전 내려받기에서 전체, 파일 형식은 JSON(또는 XML)으로 요청해요.
  3. 조금 기다린 뒤 내 정보 관리 → 사전 내려받기에서 zip 파일을 받아요.
  4. 여기서 그 zip 파일을 압축 풀지 말고 그대로 선택하세요. (압축을 푼 json/xml 파일 여러 개를 한꺼번에 골라도 돼요)

⚠️ 검색 결과 내려받기는 하루 개수 제한(약 4만 8천 개)이 있어요. 그럴 땐 매일 초성(ㄱ, ㄴ…)이나 글자별로 검색해서 나눠 받고, 받을 때마다 여기에 불러오세요. 불러온 것끼리 계속 합쳐져요. (사전 내려받기 화면에 '전체' 파일 항목이 따로 있으면 그걸 쓰세요)

파일이 크면 PC 크롬에서 하는 걸 추천해요. 우리말샘·기초사전 내용은 CC BY-SA 라이선스예요 (출처: 국립국어원).

✏️ 단어 추가 (뜻 포함)

이미 있는 단어면 뜻이 바뀌어요. 추가·수정한 단어는 규칙과 상관없이 항상 남아요.

여러 개 한꺼번에 추가

🔎 뜻 자동 찾기 설정

뜻이 없는 단어를 인터넷 사전에서 찾아와요. 찾은 뜻은 확인한 뒤에만 저장돼요.

키 받는 곳: 우리말샘 오픈 API (회원가입 → 오픈 API → 키 발급, 무료)

⚠️ 구글·나무위키는 다른 사이트에서 자동으로 가져가는 걸 막아둬요. 나무위키에만 있는 단어(캐릭터·게임 용어 등)는 아래 수집기 북마크로 모으세요. 자동 찾기에서 못 찾아 제거된 단어는 제거 목록에서 바로 내보낼 수 있어요.

🌳 나무위키 뜻 수집기 (설치 없이 · 폰 크롬 가능)

북마크 버튼 하나로, 나무위키 페이지 안에서 수집기가 열려요. 문서 첫 문장을 뜻으로 가져오고, 없으면 분류·고사성어로 대신해요. 막히면 자동으로 멈춰요.

📱 처음 한 번만: 북마크 만드는 법
  1. 위의 📋 수집기 북마크 코드 복사를 눌러요.
  2. 크롬에서 아무 페이지나 연 상태로 ⋮ 메뉴 → ☆(별)을 눌러 북마크를 추가해요.
  3. 바로 아래 뜨는 수정(또는 ⋮ → 북마크 → 방금 만든 북마크 길게 눌러 수정)을 눌러요.
  4. 이름은 kk수집, 주소(URL) 칸은 전부 지우고 복사한 코드를 붙여넣기 → 저장.
▶ 쓸 때마다: 사용 순서
  1. 단어장 탭에서 먼저 ▶ 지금 목록 끝까지 찾기(우리말샘·위키)를 돌려요.
  2. 단어장 탭의 📤 "찾아봤는데 없음" 단어만 내보내기로 파일을 받아요. (또는 📤 지금 목록의 뜻 없는 단어 내보내기)
  3. 크롬으로 namu.wiki를 열어요 (아무 문서나).
  4. 주소창에 kk수집을 입력하고, 아래 뜨는 ☆ 북마크 항목을 눌러요. → 수집기 창이 떠요. (PC는 북마크바에서 클릭)
  5. 2번 파일을 불러오면 바로 시작해요. 다 되면 ⬇ 전체 txt를 받아요. (전체로 받아야 "나무위키에도 없음"까지 기록돼요)
  6. 여기 단어장 탭의 📥 나무위키 수집 결과 불러오기 → 뜻은 저장되고, 없는 단어는 기록돼요.
  7. 마지막으로 🗑 위키·나무위키 모두 없는 단어 제거를 누르면 진짜 이상한 단어만 정리돼요.

⚠️ 주소창에 코드를 직접 붙여넣으면 크롬이 앞의 javascript:를 지워버려서 안 돼요. 꼭 북마크로 만들어서 누르세요.

💾 정리된 단어장 txt 저장

제거 목록을 뺀 단어장을 단어[뜻] 형식(한 줄에 한 단어)으로 저장해요. 게임의 "단어장 추가"에 그대로 넣을 수 있어요.

↑ 뜻을 다시 찾아볼 단어 목록이에요 (한 줄에 한 단어). 나무위키 수집기에 그대로 넣을 수 있어요. 제거 목록에 있는 단어는 빠져요.

↑ 직접 추가하거나 나무위키·사전에서 뜻을 채운 단어만 모아요. 게임의 "어인정 전용 단어장"에 올리면, 그 단어들은 어인정 모드에서만 쓰여요.

🎮 게임용 사전 파일 만들기

끝말잇기 게임(깃허브 index3)이 불러오는 사전 파일 dict1.json.gz, dict2.json.gz를 이 단어장으로 새로 만들어요. 두 파일을 깃허브에 같은 이름으로 덮어쓰기하면, 게임 사전이 정리된 단어장으로 바뀌어요. (한글이 아닌 글자가 섞인 단어·1글자 단어는 자동으로 빠져요)

📦 작업 백업

제거·살리기·추가·수정·규칙을 파일 하나로 저장해요. 다른 기기에서 단어장을 불러온 뒤 이 파일을 불러오면 이어서 할 수 있어요.
